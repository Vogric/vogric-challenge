# Demo video

- `saas-dashboard-demo.mp4` — 34-second product walkthrough, 1280×720.
- `saas-dashboard-demo-poster.png` — poster frame used by the README.

The recording is generated by `scripts/record-demo.mjs` against a running app:

```bash
npm run dev # in another terminal
node scripts/record-demo.mjs
ffmpeg -i demo/saas-dashboard-demo.webm \
  -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p -movflags +faststart \
  demo/saas-dashboard-demo.mp4
```

The source `.webm` and `demo/raw/` are ignored by Git.
